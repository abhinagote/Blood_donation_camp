# 🩸 Blood Donation Camp - DBMS Mini Project  

## 📌 Introduction  
The **Blood Donation Camp** project is a community-driven initiative aimed at ensuring a stable and sufficient blood supply. Through partnerships, awareness campaigns, and efficient data management, this system streamlines the blood donation process, making it accessible and well-organized.  

## 🚀 Features  
- **Online Registration**: Donors can register and book time slots, reducing wait times.  
- **Donor Database Management**: Stores donor details securely using a Database Management System (DBMS).  
- **Blood Availability Tracking**: Keeps real-time count of available blood units.  
- **User-Friendly Interface**: Built with HTML, CSS, JavaScript, and PHP for easy navigation.  
- **Admin Panel**: Allows authorized personnel to manage blood requests, donor details, and logs.  

## 🏗️ Technologies Used  
- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: PHP  
- **Database**: MySQL  
- **Development Tools**: Visual Studio Code, XAMPP  
- **Design Tools**: StarUML (for UML diagrams)  

## 🛠️ Installation Guide  
1. Clone the repository:  
   ```sh
   git clone https://github.com/abhinagote/blood_donation_camp.git
   ```  
2. Set up the database:  
   - Import `blood_donation.sql` into MySQL.  
   - Update database configurations in `config.php`.  
3. Start the local server (XAMPP/WAMP).  
4. Open the project in the browser: `http://localhost/blood_donation_camp`.
